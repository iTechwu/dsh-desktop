# 体验问题

## UX-001 覆盖层叠加与隐藏控件可操作

连续打开多个业务插件时，新覆盖层没有替换或关闭旧覆盖层。视觉上只看到最上层，但辅助功能树仍包含主界面及所有旧层控件，关闭一次只退回上一层。

期望：覆盖层由桌面壳统一仲裁；打开新业务面板时替换当前面板，背景和隐藏层使用 `inert`/正确的 `aria-hidden` 隔离；关闭后焦点回到触发按钮。

进展：已完成。`docker-helm.dofe.ai@8c9f508` 让 11 个面板通过统一事件互斥；`dsh-desktop@705ab05047` 与 `deepseek-harness@de9675462b` 分别为桌面自有帧和兼容帧实现背景 `inert`、弹窗内 Tab 循环和焦点归还。真实 Electron 包中打开 Dashboard 后辅助功能树只保留弹窗，Escape 后焦点返回“企业看板”。

## UX-002 Skill 管理无法完整键盘/读屏操作

Skill 管理视觉上显示分组、搜索和 112 个技能卡片，但 macOS 原生辅助功能树只包含标题、刷新和关闭。DOM 和 Chromium AX 节点完整，Tab 也能进入筛选按钮；将运行时技能行缩减为 3 项后，原生 AX 立即恢复，说明问题来自一次性渲染的超大树。

期望：使用虚拟列表或分页限制同时挂载的技能行，并确保当前可见页的筛选、搜索、技能卡片和操作按钮进入原生 AX；刷新保留上下文，关闭归还焦点。

## UX-003 极简聊天上下文成本过高

仅发送 `YOOTUN_CHAT_SMOKE_OK` 时，界面显示输入 78.3K token、输出 259 token、首 token 5.4 秒。功能可用，但新会话的固定上下文远大于用户输入。

期望：对技能目录和系统上下文使用摘要、按需检索或惰性注入；保持能力发现完整，同时降低每次请求的固定输入成本。

## UX-004 空详情面板占据主内容宽度

初始审计将问题判断为视觉占宽；复核确认详情列宽度实际已为 0，但隐藏标题、关闭按钮和占位提示仍留在 macOS 辅助功能树，读屏与键盘语义和视觉状态不一致。

期望：空态默认折叠，首次选择工具记录时展开；用户手动关闭后保持偏好。

进展：已完成。`dsh-desktop@bbcd4eb29c` 在详情列宽度为 0 时同步应用 `inert` 与 `aria-hidden`，展开时自动移除。真实 Electron 包验证工具记录可展开完整事件详情，关闭后相关节点全部退出辅助功能树。

## UX-005 侧栏品牌区需要响应式验收

当前锁定区同时展示图形品牌、乘号、头像和“优惠豚AI”，完整但信息密度高。

期望：在侧栏收起、窄窗口、125%/150% 缩放和 Windows 字体渲染下仍保持完整、不拥挤、不改变侧栏宽度。

## UX-006 本地插件更新未自动进入桌面包

业务插件使用 `file:` 依赖时，单独构建源仓库不会刷新 pnpm 安装快照。第一次重包仍携带旧插件，只有定向刷新依赖后才消费新产物；若没有真实交互回归，源码测试会产生“已修复”的假象。

期望：打包入口在构建前校验安装快照与源插件产物一致，或由明确的 workspace/版本更新契约刷新依赖；不得依靠人工删除缓存。

## UX-007 消息插件空渠道持续重试

当前 `dsh-im@2.3.0` 在读取渠道配置前先通过回环 HTTP 探测 Harness。Desktop 正确拒绝未携带能力标记的请求后，已配置和未配置渠道都会进入 30 秒永久重试，持续增加日志并造成后台唤醒。

期望：Desktop 内运行的消息插件复用 Host 进程内服务；空渠道不发起 Harness 连接。插件升级应提供版本、迁移预览、失败回滚和重启提示，避免只能卸载后重装。
